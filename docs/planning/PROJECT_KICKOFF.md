# Star Wars RP — Project Kickoff

## Objective

Consolidate Product, Game Design, UX and Architecture into a coherent MVP specification
and define the first implementation vertical slice.

## Participants

- Human Project Owner
- Product Lead
- Senior Game Designer / RPG Systems Designer
- Senior Product / UX Designer
- Principal Software Architect

## Working rule

Chat discussions are not authoritative.

A decision becomes authoritative only when incorporated into `/docs`.

## Cross-domain changes

A specialist may propose changes outside their domain but must identify them as requiring review.

Cross-domain decisions must be reviewed before implementation.

## Implementation gate

Implementation begins when:

- the core gameplay loop is defined;
- the first GM/player workflow is defined;
- major domain ownership is defined;
- the first vertical slice is accepted;
- blocking cross-domain questions are resolved.
