# Project Documentation

This directory is the authoritative source for product, game-design, UX and architecture decisions.

## Areas

- `product/` — product vision, personas, MVP scope
- `game-design/` — RPG mechanics and gameplay systems
- `ux/` — GM and player experience
- `architecture/` — software architecture and ADRs
- `planning/` — cross-domain decisions, open questions and implementation planning
